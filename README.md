# Gestion de budget

Application mobile Flutter de suivi de budget personnel : revenus, dépenses et solde.

<!-- Ajouter une capture d'écran ici, par exemple : ![Accueil](docs/home.png) -->

## Fonctionnalités

- **Dépenses** : ajout d'une dépense par catégorie et montant, liste et suppression.
- **Revenus** : ajout d'un revenu par source et montant, liste et suppression.
- **Solde** : calcul automatique du total des revenus, du total des dépenses et du solde.
- **Navigation** par barre inférieure entre l'accueil et les revenus.

## Stack technique

| Couche | Technologies |
| --- | --- |
| Mobile | Flutter, Dart |
| Gestion d'état | Provider (ChangeNotifier) |

## Lancer le projet

```bash
git clone https://github.com/Nguirane120/gestionBudget.git
cd gestionBudget
flutter pub get
flutter run
```
